# Generic Agent Adapter

Load `../SKILL.md` as the authoritative workflow. Treat files under `../references/` as normative supporting rules.

The agent may use its native shell, Git, filesystem, or coding tools to perform the procedure. Tool names are deliberately not specified by this skill.

Before mutation, the agent must establish the authorized scope. If the hosting platform cannot reliably inspect Git state or execute required validation, perform a read-only review and report that full closeout cannot be verified in that environment.
