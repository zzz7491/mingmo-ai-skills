# Generic Agent Adapter Notes

Use this adapter for compatible AI agent environments without platform-specific behavior.

- Follow `SKILL.md` as the controlling specification.
- Confirm repository/project and audit goal before material investigation.
- Use only read-only tools and commands.
- Do not infer implementation permission from audit permission.
- Keep evidence, inference, and proposal separate.
- If required evidence is inaccessible, report `BLOCKED` instead of expanding scope or permissions.
- After the Reality Baseline report, STOP and wait for explicit implementation authorization.
