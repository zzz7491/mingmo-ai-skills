# OpenCode Adapter Notes

Use this adapter when applying `phase-planner` with OpenCode or another repository-aware coding agent.

- `SKILL.md` is the controlling specification.
- Planning only; do not start edits or "quick fixes" while planning.
- Use repository evidence only to clarify planning facts when authorized; do not perform full implementation discovery unless a targeted Reality Audit is requested.
- Keep authorized touchpoints separate from likely touchpoints.
- Do not silently resolve `UNKNOWN` or `CONFLICT`.
- Output the phase plan, then STOP and wait for explicit implementation authorization.
