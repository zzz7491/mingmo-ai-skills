# Generic Agent Adapter Notes

Use this adapter for compatible AI agent environments without platform-specific behavior.

- `SKILL.md` is the controlling specification.
- Acceptance review is independent verification, not implementation.
- Implementation claims are evidence inputs.
- Do not infer Acceptance PASS from Implementation COMPLETE.
- Do not stage, commit, push, deploy, repair, or enter another phase.
- Output the four-part acceptance result and STOP.
